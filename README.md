# Business Model Canvas

Fillable and exportable Business Model Canvas template for media entrepreneurship projects.

## What it does

A single-page, browser-based version of the classic 9-block Business Model
Canvas. Students fill in each block directly in the browser — no account,
no install. Everything autosaves locally, and multiple canvases can be kept
in one browser (useful for a shared lab computer with several teams).

- **Save:** autosaves to the browser as you type
- **Export:** download your canvas as a `.json` file (to back up or hand
  off) or as a printable PDF
- **Import:** reload a `.json` export to pick up where you left off, on
  any device

## Using it

Open [the live site](https://jourinnovation.github.io/business-model-canvas/)
— no setup required. To keep a copy of your work, use **Export .json**
before switching devices or browsers.

## Hosting your own copy

This is a single dependency-free `index.html` file. Fork this repo, enable
GitHub Pages in Settings → Pages (source: `main` branch, `/root`), and it's live.
